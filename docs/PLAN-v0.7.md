# hand-sandbox v0.7 — 간헐 시각과 공간 기억, 가벼운 물건과 옆으로 잡기, 무거운 물건 자세

작성일 2026-10-25. v0.6([`PLAN-v0.6.md`](PLAN-v0.6.md)) 위에 더한다. 리서치·벤치마크·개선 기록은 [`research/perception.md`](research/perception.md)에 둔다. 벤치마크는 시간 측정이 아니라 기준 점수 시험이다. 엔진(그룹 A)과 채점(그룹 B) 출처는 v0.6처럼 나누고 소스 검사로 강제한다.

## 0. 요청과 반영 (설계)

| 요청 | 설계 |
|---|---|
| 사람처럼 눈을 깜빡여도 공간 지각으로 걷고 잡는다 → 비전·ML을 늘 켜지 말고 일정 패턴으로 띄엄띄엄 스캔 | 시각 일정(`hand-runtime::vision`): 깜빡임 같은 켜짐/꺼짐 창 + 적응 응시(다음 행위의 허용 오차보다 예측 σ가 커질 때만 봄). 스캔 수가 계산 비용 지표 |
| 비어 있는 동안에도 이동과 `행위`는 이어짐 | 꺼진 동안 이동·행위는 기억한 위치로 계속. 기억은 로봇의 오도메트리 좌표(믿음 좌표)에 저장 |
| 그 추측은 시계열 + 삼각 측량 + SDS 분포 종합 | 기억 위치 = 삼각 측량 고정점들의 시계열 예측(last·EWMA·Holt·TTM 융합). 예측 σ = 관측 σ ⊕ 이동 거리에 비례하는 드리프트. 드리프트 비율은 다시 볼 때의 혁신(innovation)으로 SDS가 학습 |
| 최적화와 정밀도가 맞물림 → 기존 리서치 기준 벤치마크 점수 유지, 벤치맥싱 금지 | 기존 점수(행위 · 효과 · N:N · 퀘스트)를 전후로 비교. 새 칸은 사람 측정(그룹 B)으로 채점, 엔진은 그룹 A만 |
| 가벼운 물건 배치 | 새 물건 `택배 상자`(골판지): 월드 생성 때 맵 곳곳과 베이스캠프 앞에 놓임. 노드에서 나오지 않으므로 시각으로 찾고 손으로 닿아 확인 |
| 베이스캠프: 시각적으로는 앞에 있지만 오른쪽에서 잡는 시나리오, 보이지 않아도 시도 | 앞에서 본 상자를 지나가며 오른쪽에 두고 오른팔을 옆으로 뻗어 기억으로 잡음(어깨 외전). 카메라 시야(수평 70°) 밖이므로 기억 σ가 허용 안이면 보지 않고 시도, 아니면 몸을 돌려 봄 |
| 나무·바위를 잡는 기존 자세는 그대로 | 채취 자세와 원목·돌의 앞 굽혀 잡기 계획은 바꾸지 않음(같은 계획기, 같은 결과) |
| 가벼운 물건과 무거운 물건 자세: 무거운 건 무릎을 굽히는 등 디테일과 안정성 | 가벼운 물건: 한 팔 옆 뻗기(외전 + 쪼그림), 기억 조준. 무거운 물건: 앞 굽혀 잡기가 버티지 못하거나 안정 여유가 낮을 때 발을 넓혀(걸터서기) 무릎을 굽히고 짐을 몸 가까이, 두 팔, 느린 들기, 들기 중 동적 ZMP |
| 남은 제안 작업 | 이어서: LIPM 너머 보행(두 봉우리 반력, 발뒤꿈치–발끝 구르기), 바닥에 닿는 바퀴 프리셋 |

## 1. 믿음 좌표와 오도메트리 드리프트

- 월드는 참 자세를 그대로 두고, `world_sim::odometry`가 로봇이 믿는 자세와의 강체 변환(드리프트)을 이동마다 쌓는다: 진행 방향 축척 오차, 횡 무작위 보행, 자이로 바이어스. 수치는 그룹 A 출처.
- 런타임(로봇의 마음)은 믿음 좌표만 쓴다: 자기 위치, 랜드마크, 떨어진 물건 기억. 명령을 낼 때 월드가 믿음 좌표를 참 좌표로 옮긴다(로봇이 오도메트리로 그 자리까지 간 결과).
- 상대 오차(물건이 나에 대해 어디 있다고 믿는가 − 실제)는 마지막으로 본 뒤의 드리프트와 같다. 잡기의 조준 오차에 그대로 더해진다.
- 다시 보면 관측 오차만 남는다. 지도에 있는 웨이포인트 패드에서 재위치 추정.

## 2. 시각 일정

- 패턴 창: 켜짐 · 꺼짐 길이(사람의 깜빡임·시각 표집 출처는 그룹 B라 엔진에 쓰지 않음; 엔진 창은 카메라·인식 주기와 로봇 계산 예산에서 정함).
- 적응 응시: 다음 행위의 허용 오차(잡기는 물체 윗면 반폭, 접근은 손 닿는 거리)와 예측 σ를 비교. 대상이 시야 밖이면 보지 않고 시도하거나 몸을 돌려 봄 — 기대 비용으로 고름.
- ML 패스: 키프레임(ML 켜짐) 사이의 이동은 이미 눈을 감은 상태. 고정점이 좋으면 예측 σ가 허용을 넘을 때까지 여러 홉을 보지 않고 감.

## 3. 자세

- 어깨 외전(롤) 자유도: 팔의 시상면 사슬을 어깨의 앞뒤 축으로 돌림. 외전 0이면 기존 결과와 같음(관절 목록도 같음).
- 옆 뻗기 계획 `act::reach::plan_side`: 다리·고관절·허리와 외전 + 2링크 IK, 노력 최소, 측면 ZMP 포함.
- 무거운 물건: 걸터서기(발 사이에 물건), 엇갈린 발, 두 팔, 느린 들기 후보. 기존 계획이 버티는 원목·돌은 그대로.

## 4. 벤치마크 (그룹 B, 엔진에 쓰지 않음)

- 사람의 눈 감고 걷기 오차(거리 대비 %), 기억 유도 뻗기 오차 vs 지연, 간헐 시각 보행의 시각 사용 비율.
- 기존 점수 유지 확인: `action_bench`, 효과 벤치, N:N, 런타임 퀘스트.

## 5. 구현하며 더한 것

- 목적지: 8 m 안에서 깃발을 봐 위치 보정(검증 게이트로 잘못 읽은 깃발을 버림), 믿음상 덜 왔으면 마저 걷기, 손이 더미에 안 닿으면 보고 다가가기.
- 보정과 기억을 한 좌표계로: 보정은 다음 결정 단계 시작에 적용하고, 기억은 본 때까지의 드리프트 몫만큼 함께 옮김.
- SDS 드리프트 학습을 분산 영역으로(관측마다 제곱근을 취하면 율이 절반쯤으로 낮게 나와 기억을 과신함).
- 왕복은 서 있던 자리로 돌아감, 헛잡기는 기억 σ를 올려 다음엔 먼저 봄, 보이지 않는 조각은 돌아서 봄, 기억한 조각으로 가는 길에도 패턴 응시.
- LIPM 너머 보행(§1.6 of research): CoM 수직 진폭(Massaad 2007) + 발꿈치→발끝 압력 중심(Jeon & Cho 2020), 주기 해, 최대 기울기로 필요 마찰.
- 바퀴형 바닥 집기: 몸통 리프트(Fetch 급 0.40 m · 0.1 m/s · 450 N) + 고급 허리 피치 = `wheel_lift` 프리셋.

결과와 단계별 점수는 [`research/perception.md`](research/perception.md) §4–§5.
